# HORIZON BREAKER

Three.js で構築した、PC・スマートフォン両方で遊べる 3D 横スクロールアクションゲームです。
ブラウザだけで動作する単一 HTML ファイルのゲームとして提供されています。

## ゲーム名

HORIZON BREAKER

## 概要

HORIZON BREAKER は、横長画面前提で設計された 3D 横スクロールアクションゲームです。
プレイヤーはステージを右へ進み、敵を倒しながら進行し、ステージ末尾のボスを撃破します。

ゲーム本体は単一の HTML ファイルとして構成されています。
Three.js は CDN 経由で読み込まれます。

## 対応言語

アプリの UI は以下の言語に対応しています。

| コード | 言語 |
| --- | --- |
| en | English |
| ja | 日本語 |
| ko | 한국어 |
| zh | 简体中文 |
| es | Español |

言語切り替えはアプリ内の設定メニューから変更できます。

## 主な機能

- Three.js を使用した 3D 横スクロールアクション
- PC のキーボード操作に対応
- スマートフォンではタッチボタンで操作可能
- 横長画面向けのゲーム UI
- 縦画面では回転案内を表示
- サウンド ON / OFF 切り替え
- 多言語対応 UI
- ローカルストレージへの進行度保存
- 敵の種類を複数実装
- 複数ステージを進行可能
- 複数種類のボス戦を実装
- ステージクリアで次のステージを解放
- スコア、コイン、戦闘数などの記録

## 推奨環境

- 最近のブラウザ
- WebGL に対応した環境
- JavaScript が有効なブラウザ
- ローカルストレージが利用できる環境

スマートフォンでは横画面でのプレイを推奨します。

## ファイル構成

このプロジェクトは通常、以下のファイルで構成します。

- index.html
  - ゲーム本体の HTML
  - Three.js 呼び出し
  - 描画処理
  - 入力処理
  - 言語切替
  - 保存処理
  - サウンド制御

## 遊び方

1. ゲームファイルを保存します。
2. ファイルを index.html として保存します。
3. ブラウザで index.html を開きます。
4. メニューからゲームを開始します。
5. ステージを右へ進み、ボスを倒すとステージクリアです。

## 操作方法

### PC 用キーボード操作

- 左移動：左矢印キー
- 右移動：右矢印キー
- 左移動：A キー
- 右移動：D キー
- ジャンプ：W キー
- ジャンプ：スペースキー
- 斬撃：X キー
- 射撃：Z キー
- ポーズ：P キー
- ポーズ：Esc キー

### スマートフォン用タッチ操作

- 左ボタン：左移動
- 右ボタン：右移動
- 上矢印ボタン：ジャンプ
- A ボタン：斬撃
- S ボタン：射撃

画面右下にある全画面ボタンで、対応端末では全画面表示を試行できます。

## ゲームシステム

プレイヤーは右へ移動しながらステージを攻略します。
敵を倒すとスコアが増加し、コインを取得すると追加ポイントが入ります。
敵の種類によって行動パターンが異なります。

ステージ途中にはチェックポイントが設定される場合があります。
チェックポイントを通過すると、そこから再開しやすくなります。

ステージ末尾にはボスが出現します。
ボスは種類ごとに異なる攻撃パターンを持ちます。
ボスを倒すとステージクリアとなり、次のステージが解放されます。

## 敵について

敵は種類ごとに移動方法、攻撃方法、耐久力が異なります。
一部の敵は接近してくるタイプ、射撃してくるタイプ、空中を移動するタイプなどが存在します。

敵は単に数が増えるだけでなく、ステージ進行に応じて種類が変化します。

## ボスについて

ボスはステージに応じて複数種類が出現します。
ボスは体力が多く、攻撃パターンも複雑です。
突進、砲撃、ジャンプ、召喚、レーザー、追跡、全方位攻撃など、種類ごとに異なる挙動を持ちます。

ボス戦では、攻撃回避と反撃のタイミングが重要です。

## データ保存

ゲーム進行度はブラウザのローカルストレージに保存されます。
保存される内容は、次のような項目です。

- 解放済みステージ番号
- 選択中の言語
- サウンド設定
- コイン取得数
- 死亡回数
- 倒した敵数
- 累計スコア

ブラウザのキャッシュやデータを削除すると、セーブデータが消える場合があります。

## サウンド

サウンドは設定メニューから ON / OFF を切り替えられます。
ゲーム内効果音は Web Audio API などで生成される簡易的な音になります。

一部のブラウザでは、最初のユーザー操作後に音が有効化されます。
音が出ない場合は、ページ内のボタンに触れてから設定を確認してください。

## 画面回転について

このゲームは横長画面を前提にしています。
スマートフォンやタブレットが縦画面の場合、回転案内が表示されます。
横画面に回転させてからプレイしてください。

## トラブルシューティング

### 画面が真っ黒な場合

- ブラウザが WebGL に対応していない可能性があります。
- JavaScript が無効になっている可能性があります。
- Three.js の読み込みに失敗している可能性があります。

### 音が鳴らない場合

- サウンド設定が OFF になっている可能性があります。
- ブラウザの自動音声制限に引っかかっている可能性があります。
- ページ内のボタンに触れてから再度お試しください。

### セーブデータが消える場合

- ブラウザのプライベートモードで保存されていない可能性があります。
- ブラウザのストレージが削除された可能性があります。
- 端末のストレージ容量が不足している可能性があります。

### 動作が重い場合

- 他のブラウザタブを閉じてください。
- 端末の省電力モードを解除してください。
- 縦長画面では描画がうまく機能しない場合があります。横画面でお試しください。
